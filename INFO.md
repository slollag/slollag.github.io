# Sebastian Gallo - Personal Website

A minimal, systems engineer-focused personal website with a clean black and white design.

## Design Philosophy

- **Minimal**: Clean, uncluttered interface focused on content
- **Systems-focused**: Monospace font (Consolas) and terminal-like aesthetic
- **Constrained**: Content limited to the middle 50% of the screen
- **Color scheme**: Black background, white text, red (#dc2626) accents

## Features

- **Responsive Design**: Adapts to different screen sizes while maintaining the 50% content constraint
- **Minimal Navigation**: Simple, clean navigation without animations
- **Systems Aesthetic**: Monospace font and terminal-like styling
- **Downloadable Resume**: Direct link to download resume as PDF
- **Smooth Scrolling**: Navigation links smoothly scroll to sections

## Sections

1. **Hero**: Introduction with name and key focus areas
2. **About**: Personal background and key statistics
3. **Experience**: Work history in clean, minimal format
4. **Projects**: Featured projects with technologies and descriptions
5. **Contact**: Contact information and social media links

## Technologies Used

- HTML5
- CSS3 (minimal styling)
- Vanilla JavaScript (minimal functionality)
- Consolas font family

## Setup Instructions

1. Clone or download the project files
2. Add your resume PDF file as `resume.pdf` in the root directory
3. Update the social media links in `index.html` with your actual profiles
4. Open `index.html` in a web browser

## Customization

### Colors
The website uses a minimal color scheme:
- Background: `#000000` (black)
- Text: `#ffffff` (white)
- Accents: `#dc2626` (red)
- Secondary text: `#cccccc` (light gray)
- Muted text: `#999999` (gray)

### Content
- Update personal information in `index.html`
- Modify the about section text
- Add or remove experience items
- Update project descriptions and technologies

### Layout
- Content is constrained to 50% of screen width
- Responsive breakpoints adjust this constraint for smaller screens
- Maintains the minimal aesthetic across all devices
